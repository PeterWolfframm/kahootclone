# Kahoot clone

Live quiz games on **SpacetimeDB** with quiz storage and auth on **Supabase**.

- App: https://play.happylittleventures.com
- Join PIN on phones, host on a big screen
- Create kahoots: quiz, true/false, multi-select, type answer, slider

## Design system

UI is the **Keypad** kit (brutalist / haptic). Tokens, Tailwind recipes, and React primitives live in [`src/design-system/`](src/design-system/README.md). Open `/showcase` for the admin dashboard and the living spec (System tab).
